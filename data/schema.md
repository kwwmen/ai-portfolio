# Схема данных

Все данные сайта лежат в папке `data/` в виде JSON-файлов.
Код эти файлы только читает — менять разметку при добавлении контента не нужно.

---

## `site.json` — контакты, тексты главной, навигация

| Поле | Тип | Описание |
|---|---|---|
| `brand` | string | Логотип в шапке и в подвале |
| `name` | string | Полное имя — подвал, копирайт |
| `tagline` | string | Подзаголовок в `<title>` браузера |
| `heroEyebrow` | string | Мелкая строка над заголовком |
| `heroTitle` | string | Заголовок. Часть после `\|` выделяется акцентным курсивом |
| `heroLead` | string | Вводный абзац |
| `contacts` | array | Телефон, почта, мессенджеры |
| `nav` | array | Пункты меню. `"optional": true` — скрывается на узких экранах |
| `footer.about` | string | Абзац о направлении в подвале |
| `year` | number | Год в копирайте |

**Контакт:**
```json
{ "label": "Telegram", "value": "@kwwmen", "href": "https://t.me/kwwmen" }
```

Первый контакт из массива становится основной кнопкой в шапке героя.

## `cases.json` — кейсы

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `id` | string | да | Уникальный идентификатор, латиницей |
| `number` | number | да | Номер кейса. Выводится как «№01» |
| `status` | string | да | `published` — виден всем. `demo` — с меткой Demo |
| `title` | string | да | Название |
| `task` | string | нет | Какая была задача |
| `actions` | string[] | нет | Что сделали. Выводится нумерованным списком |
| `result` | string | нет | Результат. В карточке показываются первые две строки |
| `price` | string \| null | нет | Например `"15 000 ₽"`. `null` — блок не показывается |
| `video` | string \| null | нет | Ссылка YouTube или ID |
| `photos` | string[] | нет | Пути к фото |
| `testimonialId` | string \| null | нет | `id` отзыва из `testimonials.json` |
| `extra` | array | нет | Резерв под дополнительные материалы |

**Если поля нет или оно `null` — блок просто не отрисуется.** Пустых заголовков не будет.

**Формат ссылки на видео** — любой из вариантов:
```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
https://youtu.be/dQw4w9WgXcQ
dQw4w9WgXcQ
```

**Пути к фото** — при `mediaSource: "local"`:
```json
"photos": ["/Photo/case-3/foto-1.jpg", "/Photo/case-3/foto-2.jpg"]
```
означает файлы `assets/img/cases/case-3/foto-1.jpg` и `foto-2.jpg`.

Можно указать и полный https-адрес — он будет использован как есть.

## `testimonials.json` — отзывы

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный идентификатор |
| `quote` | string | Текст отзыва. Кавычки добавятся сами — не пишите их |
| `author` | string | Имя |
| `role` | string | Должность или компания |
| `caseId` | string \| null | Привязка к кейсу |

**Если массив отзывов пуст — секция «Отзывы» целиком скрывается.** Пустого блока на сайте не будет.

## Типичные ошибки

**Забытая запятая между объектами** — самый частый случай:
```json
  { "id": "case-1" }      ← запятая здесь обязательна
  { "id": "case-2" }
```

**Лишняя запятая после последнего объекта** — тоже ошибка:
```json
  { "id": "case-2" },     ← это сломает файл
]
```

**Кавычки.** В JSON только двойные `"`. Одинарные `'` недопустимы.

**Проверка файла.** Скопируйте содержимое на `jsonlint.com` — он покажет строку с ошибкой.
