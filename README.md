# kwwmen — AI photo-to-video portfolio

Личный сайт-портфолио Меньшикова Фёдора. AI-анимация фотографий.

## Как добавить кейс

Откройте `data/cases.json` и добавьте новый объект в массив:

```json
{
  "id": "case-3",
  "number": 3,
  "status": "published",
  "title": "Название кейса",
  "task": "Что просил клиент — 2-3 предложения",
  "actions": [
    "Шаг первый",
    "Шаг второй",
    "Шаг третий"
  ],
  "result": "Что получилось в итоге",
  "price": null,
  "video": "https://youtu.be/XXXXXXXXXXX",
  "photos": [],
  "testimonialId": null,
  "extra": []
}
```

**Правила:**
- `status`: `"published"` — виден всем, `"demo"` — помечен демо-меткой
- `video`: принимает полную ссылку YouTube, короткую youtu.be или просто ID
- `photos`: массив путей вида `"/Photo/case-3/foto-1.jpg"` или https-ссылок
- `price`: строка `"5000 ₽"` или `null` — тогда не показывается
- `testimonialId`: id отзыва из `testimonials.json` или `null`
- Если поля нет — ставьте `null`. Пустые блоки не отрисовываются.

**Удалить демо-кейсы:** найдите записи с `"status": "demo"` и удалите их.

## Как добавить отзыв

Откройте `data/testimonials.json`:

```json
{
  "id": "testimonial-1",
  "quote": "Текст отзыва без кавычек — они добавятся автоматически",
  "author": "Имя Фамилия",
  "role": "Должность, Компания",
  "caseId": "case-3"
}
```

- `caseId` — привязывает отзыв к кейсу (показывается в модальном окне)
- Если отзыв не привязан к кейсу — ставьте `null`

## Как добавить услугу

Откройте `data/services.json`:

```json
{
  "id": "service-4",
  "title": "Название услуги",
  "description": "Описание — что делаете, для кого подходит",
  "price": "по запросу",
  "formats": ["Формат 1", "Формат 2"]
}
```

## Как заменить видео в кейсе

Найдите нужный кейс в `data/cases.json`, замените значение поля `video`:

```json
"video": "https://youtu.be/НОВЫЙ_ID"
```

## Как добавить фотографии к кейсу

**Вариант A — хранить в GitHub (рекомендуется для оптимизированных фото):**
1. Создайте папку `assets/img/cases/case-3/`
2. Загрузите туда WebP/JPEG файлы (оптимизированные, до 250 КБ каждый)
3. В `cases.json` укажите пути:
   ```json
   "photos": ["/Photo/case-3/foto-1.jpg", "/Photo/case-3/foto-2.jpg"]
   ```

**Вариант B — хранить на Яндекс Диске:**
1. В `assets/js/config.js` измените `mediaSource: 'local'` на `mediaSource: 'yandex'`
2. Там же впишите `publicKey` — ссылка на публичную папку на Диске
3. Пути в `photos` — относительные пути внутри папки Диска: `"/Photo/case-3/foto-1.jpg"`

> ⚠️ Яндекс Диск имеет нелимитированный, но непредсказуемый лимит на скачивание.
> При большой аудитории фото могут переставать грузиться. Лучше хранить
> оптимизированные версии (WebP, ≤250 КБ) в GitHub, а оригиналы — на Диске.

## Как обновить контакты и тексты

Откройте `data/site.json` — там все тексты главной страницы, контакты и навигация.
Редактируйте прямо на GitHub: откройте файл → карандаш → сохраните.

## YouTube — технические детали

Плеер — фасад: до клика загружается только картинка-превью (~20 КБ вместо ~800 КБ скриптов YouTube). После клика появляется настоящий iframe с плеером. Используется `youtube-nocookie.com` — не передаёт куки до взаимодействия.

Принимаемые форматы ссылок:
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`
- `dQw4w9WgXcQ` (просто ID)

## Как публикуется сайт

```
Вы меняете файл в репозитории
        ↓
GitHub Actions запускает deploy.yml
        ↓
Сайт обновляется на GitHub Pages (~30–60 сек)
```

Статус деплоя: вкладка **Actions** в репозитории.
Зелёная галочка = сайт обновлён.

## Локальный запуск

Сайт не открывается двойным кликом по `index.html` — браузер блокирует загрузку JSON с диска.

Запустить локально:
```bash
# Python (есть на macOS и Linux, устанавливается с python.org на Windows)
cd путь/к/ai-portfolio
python -m http.server 8000
# открыть http://localhost:8000

# Или в VS Code: расширение Live Server → правый клик по index.html
```

## Скрытая папка .github

На Windows проводник может не показывать папку `.github`.
Включите отображение скрытых файлов: **Вид → Показать → Скрытые элементы**.
На macOS: `Cmd + Shift + .`

Без этой папки автодеплой не будет работать.
