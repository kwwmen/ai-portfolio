# kwwmen — портфолио

Личный сайт Меньшикова Фёдора. AI-анимация фотографий.

---

## Структура

```
ai-portfolio/
├── index.html                  ← каркас страницы
├── .nojekyll                   ← отключает Jekyll на GitHub Pages
├── .github/workflows/deploy.yml ← автодеплой при коммите в main
├── assets/
│   ├── css/
│   │   ├── tokens.css          ← цвета, шрифты, отступы, тайминги анимаций
│   │   ├── base.css            ← reset, типографика, появление при скролле
│   │   ├── layout.css          ← шапка, герой, секции, подвал
│   │   └── components.css      ← карточки, модалка, галерея, lightbox
│   ├── js/
│   │   ├── main.js             ← точка входа: грузит JSON и строит страницу
│   │   ├── config.js           ← настройки проекта
│   │   ├── components/         ← UI-элементы
│   │   └── lib/                ← утилиты (dom, media, motion, format)
│   └── img/                    ← favicon, заглушка, og-cover
└── data/
    ├── site.json               ← контакты, тексты, навигация
    ├── cases.json              ← КЕЙСЫ
    ├── services.json           ← услуги
    ├── testimonials.json       ← отзывы
    └── schema.md               ← описание всех полей
```

## Как добавить кейс

Откройте `data/cases.json`, добавьте объект в массив:

```json
{
  "id": "case-3",
  "number": 3,
  "status": "published",
  "title": "Название кейса",
  "task": "Что просил клиент",
  "actions": ["Шаг первый", "Шаг второй"],
  "result": "Что получилось",
  "price": null,
  "video": "https://youtu.be/XXXXXXXXXXX",
  "photos": [],
  "testimonialId": null,
  "extra": []
}
```

**Обязательно:** между объектами ставится запятая. После последнего — не ставится.
Проверить файл можно на `jsonlint.com`.

Полное описание полей — в `data/schema.md`.

**Если поля нет или оно `null` — блок на сайте не появится.** Пустых заголовков и заглушек не будет.

## Как добавить видео

Нужна ссылка на ролик с YouTube. Подойдёт любой формат:

```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
https://youtu.be/dQw4w9WgXcQ
dQw4w9WgXcQ
```

Вставьте её в поле `video` нужного кейса. Карточка автоматически возьмёт стоп-кадр с YouTube как превью.

**Как работает плеер:** до клика загружается только картинка (~30 КБ). После клика подгружается настоящий плеер. Это ускоряет страницу примерно в 20 раз по сравнению с обычной вставкой iframe.

Ролик на YouTube можно держать в статусе «Доступ по ссылке» — на сайте он будет виден, в поиске YouTube — нет.

## Как добавить фотографии

1. Создайте папку `assets/img/cases/case-3/`
2. Загрузите файлы — оптимизированные, до 250 КБ каждый (WebP или JPEG)
3. В `cases.json` укажите:

```json
"photos": ["/Photo/case-3/foto-1.jpg", "/Photo/case-3/foto-2.jpg"]
```

Клик по фото в кейсе открывает полноэкранный просмотр со стрелками и свайпами.

## Как добавить отзыв

`data/testimonials.json`:

```json
{
  "id": "testimonial-1",
  "quote": "Текст отзыва без кавычек — они добавятся сами",
  "author": "Имя Фамилия",
  "role": "Должность или компания",
  "caseId": "case-3"
}
```

`caseId` связывает отзыв с кейсом — он появится внутри модального окна этого кейса.
Не хотите связывать — поставьте `null`.
**Если отзывов нет, секция «Отзывы» целиком скрывается.**

## Публикация

```
правите файл
     ↓
GitHub Desktop: Commit to main
     ↓
GitHub Desktop: Push origin
     ↓
GitHub Actions собирает сайт (~30 сек)
     ↓
сайт обновился
```

Статус — вкладка **Actions** в репозитории. Зелёная галочка = всё в порядке.

## Локальный просмотр

Двойной клик по `index.html` не сработает — браузер блокирует загрузку JSON с диска. Это нормально.

```bash
cd путь/к/ai-portfolio
python -m http.server 8000
# открыть http://localhost:8000
```

Или в VS Code: расширение **Live Server** → правый клик по `index.html`.

## Яндекс Диск

По умолчанию фото берутся из GitHub (`mediaSource: "local"`).

Чтобы переключить на Яндекс Диск, в `assets/js/config.js`:

```js
mediaSource: 'yandex',
yandex: { publicKey: 'https://disk.yandex.ru/d/XXXXXXX' }
```

**Честное предупреждение.** Публичный API Яндекс Диска отдаёт временную ссылку на файл, и количество таких запросов в сутки ограничено. Точный порог Яндекс не публикует. При живом трафике часть посетителей может увидеть вместо фото заглушку.

Поэтому:

| Что | Где хранить | Почему |
|---|---|---|
| Фото на сайте (WebP, ≤250 КБ) | GitHub, `assets/img/cases/` | Быстро, без лимитов, кэшируется |
| Видео | YouTube | Бесплатный транскодинг, адаптивное качество |
| Оригиналы, RAW, доп. материалы | Яндекс Диск | Архив и раздача по ссылке |

Яндекс Диск остаётся вашим архивом, но витрина сайта от него не зависит.

## Скрытая папка .github

Windows может не показывать её в проводнике.
Включите: **Вид → Показать → Скрытые элементы**.
Без папки `.github` автодеплой работать не будет.

## Что меняется при правках

| Задача | Какие файлы трогать |
|---|---|
| Новый кейс | `data/cases.json` |
| Заменить видео | `data/cases.json` |
| Новый отзыв | `data/testimonials.json` |
| Новая услуга | `data/services.json` |
| Контакты | `data/site.json` |
| Цвета всего сайта | `assets/css/tokens.css` |
| Дизайн карточки кейса | `assets/css/components.css` + `components/CaseCard.js` |

Остальные файлы при точечных правках не трогаются.
