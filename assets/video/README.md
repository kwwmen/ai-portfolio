# Свои видеофайлы

Положите сюда MP4 — и ролики будут показываться **напрямую с вашего сайта**.
Это самый надёжный способ: не нужен ни YouTube, ни VPN, ни доступ к VK.
Если сайт открылся — откроется и видео.

## Как подключить

1. Сожмите ролик до **10–15 МБ** (см. ниже)
2. Положите файл сюда, например `case-7.mp4`
3. Откройте `data/cases.json`, найдите нужный кейс и впишите имя файла:

```json
"video": {
  "mp4": "assets/video/case-7.mp4",
  "rutube": null,
  "vk": null,
  "youtube": "https://youtu.be/n7SkAvXzGXM"
}
```

4. Сохраните → Commit → Push

Готово. Пока поле `mp4` пустое, сайт берёт следующий источник
по порядку из `assets/js/config.js`:

```js
videoOrder: ['mp4', 'rutube', 'vk', 'youtube']
```

**Проверка:** если в `mp4` указан путь, а файла нет — плеер молча
переключится на следующий доступный источник. Сайт не сломается.

## ⚠️ Про лимит GitHub

У GitHub Pages — около **100 ГБ трафика в месяц**. Это не жёсткий запрет,
но при превышении сайт могут притормозить.

Считаем честно:

| Размер ролика | Просмотров до лимита |
|---|---|
| 8 МБ | ~12 000 |
| 15 МБ | ~6 500 |
| 30 МБ | ~3 300 |

Для портфолио, которое вы показываете клиентам, запаса хватает с головой.
Если начнёте крутить рекламу и пойдёт большой трафик — переходите на
внешний хостинг (Kinescope, Bunny, VK).

## Как сжать видео

### Вариант 1: HandBrake (бесплатно, с картинками)

1. Скачайте **handbrake.fr**
2. Откройте ролик
3. Пресет: **Web → Gmail Large 3 Minutes**
4. Вкладка **Video**: качество `RF 24`, кодек `H.264`
5. Вкладка **Audio**: битрейт `128`, стерео
6. **Start**

На выходе 15-секундный ролик 1080p весит примерно 5–8 МБ.

### Вариант 2: командная строка (ffmpeg)

```bash
# 1080p, хорошее качество
ffmpeg -i исходник.mp4 -c:v libx264 -crf 24 -preset slow \
       -vf "scale=1920:-2" -c:a aac -b:a 128k -movflags +faststart case-7.mp4
```

Что здесь важно:

- `-crf 24` — качество. Меньше число = лучше картинка и больше файл.
  Разумный диапазон: 22–26.
- `-movflags +faststart` — **обязательно**. Переносит оглавление в начало
  файла, иначе видео начнёт играть только после полной загрузки.
- `scale=1920:-2` — 1080p с сохранением пропорций.

Для вертикального видео:

```bash
ffmpeg -i исходник.mp4 -c:v libx264 -crf 24 -preset slow \
       -vf "scale=1080:-2" -c:a aac -b:a 128k -movflags +faststart short.mp4
```

## Стоит ли переходить на свои файлы

**Плюсы:** работает у всех и всегда, нет рекламы, нет чужих логотипов,
мгновенный старт, полный контроль.

**Минус:** трафик ваш, и он ограничен.

**Разумный компромисс:** держать в репозитории 2–3 лучших ролика,
остальные — на внешнем хостинге. Тогда превью-работы открываются
мгновенно даже у тех, у кого закрыт доступ к видеохостингам.
